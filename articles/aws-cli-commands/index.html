AWS CLI コマンド索引 aws-cli 2.35.11 / 2026-09-04

AWS CLI v2 のうち、実務で頻度の高いものをサービス別に並べた一覧。 コマンド名と実行例はクリックでコピーできる。 出力が巨大になりがちなので、--query と --output を併記した実行例にしている。 取り返しのつかない操作には 破壊的 の印を付け、実行例には「先に確認するためのコマンド」を置いた。

該当なし

注記
  • 対象は AWS CLI v2(2.35.11)。v1 では一部のサブコマンドやオプションが異なる。
  • コマンドの選定は実務での使用頻度によるもので、網羅ではない。全一覧は aws <service> help で引くこと。
  • 実行例のアカウントID・リージョン・リソース名は代表例。自分の環境に読み替えること。
  • --query は手元での絞り込み、--filters はサーバー側での絞り込み。大量データでは後者を優先する。
  • 破壊的の行の実行例は、削除コマンドそのものではなく実行前に確認するためのコマンドを載せている。
