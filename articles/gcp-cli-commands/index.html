gcloud コマンド索引 Google Cloud CLI / 2026-09-04

Google Cloud CLI(gcloud と bq)のうち、実務で頻度の高いものをサービス別に並べた一覧。 コマンド名と実行例はクリックでコピーできる。 全コマンド共通の --format / --filter を併記した実行例にしている。 取り返しのつかない操作には 破壊的 の印を付け、実行例には「先に確認するためのコマンド」を置いた。

注記
  • このページは 公式ドキュメントに基づく。この端末に gcloud が入っていないため、AWS 版のようなローカル実行での検証はしていない。
  • コマンドの選定は実務での使用頻度によるもので、網羅ではない。全一覧は gcloud <group> --help で引くこと。
  • gsutil は gcloud storage に置き換わっている。新規に書くなら後者を使う。
  • gcloud auth login(CLI用)と gcloud auth application-default login(アプリ用)は別物。ライブラリが認証できないときは後者を疑う。
  • 破壊的の行の実行例は、削除コマンドそのものではなく実行前に確認するためのコマンドを載せている。
