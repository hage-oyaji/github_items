Git コマンド索引 git 2.54.0 / 2026-09-04
▸

Git 2.54.0 の git help -a をもとに、実務で使う単位へ組み替えた一覧。 冒頭の 定番の流れ は clone からブランチ作成・編集・push までを実行順に並べた3セット。 コマンド名と実行例はクリックでコピーできる。 取り返しのつかない操作には 破壊的 / 履歴改変 / 共有NG の印を付けた。

該当なし

注記
  • コマンドの分類は git help -a(git 2.54.0)の Main Porcelain / Ancillary をもとにしている。
  • オプションは実務で使う頻度が高いものに絞った。網羅的な一覧は git help <command> を見ること。
  • 実行例のブランチ名・SHA・URLは代表例。自分の環境に読み替えること。
  • 破壊的は未コミットの変更やオブジェクトが失われる操作、履歴改変はSHAが変わる操作、共有NGは他人の作業を壊す操作を指す。
  • git filter-branch は公式に非推奨で、代替は外部ツールの git filter-repo。
