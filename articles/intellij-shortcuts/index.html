IntelliJ IDEA ショートカット索引 Default / macOS キーマップ

IntelliJ IDEA の Default キーマップ(Windows / Linux) と macOS キーマップを並記した一覧。 キーはクリックでコピーできる。 記号は Cmd = ⌘、Opt = ⌥。「Shift Shift」は Shift を素早く2回押す操作を指す。

該当なし

注記
  • このページは 公式の既定キーマップに基づく。ローカル環境からの抽出ではないため、自分の割当は Settings → Keymap で確認すること。
  • IDE や製品(IDEA / PyCharm / WebStorm / Rider など)、バージョン、導入プラグインによって割当が変わることがある。
  • — は既定のショートカットが割り当てられていない操作。メニューまたは Find Action から実行する。
  • macOS 列は「macOS」キーマップ。「macOS System Shortcuts」キーマップを選んでいる場合は一部異なる。
  • キーマップ全体の一覧は Help → Keymap Reference から PDF で出せる。
