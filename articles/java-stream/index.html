Java Stream 早見表 Java 21 LTS 基準 / 2026-09-04

Java の java.util.stream を、パイプラインの流れ(生成 → 中間 → 終端)の順に並べた早見表。 メソッド名と実行例はクリックでコピーできる。 シグネチャは公式 Javadoc の記載どおり。導入バージョンを併記しているので、 Java 8 や 11 の環境では「Java 16+」などの表記を確認してから使うこと。

該当なし

注記
  • シグネチャと説明は 公式 Javadoc(Java SE 21)を確認して作成している。Gatherers のみ Java SE 25 の Javadoc を参照した。
  • 導入バージョンの表記がないものは Java 8 から使える。「Java 9+」などの表記は、そのバージョン以降でのみ利用できることを示す。
  • Stream.gather と Gatherers は Java 24 で正式化された(Java 22・23 ではプレビュー機能)。
  • 実行例の User / Order はレコードを想定した架空の型。User::name のようなアクセサ名は読み替えること。
  • 中間操作は遅延評価で、終端操作を呼ぶまで実行されない。ストリームは終端操作1回で使い切りになる。
