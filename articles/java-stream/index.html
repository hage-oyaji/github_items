Stream を初めて触る人向けの早見表。 最初の「Stream とは」を読めば、あとは辞書として引ける。 すべての実行例に結果を書いているので、何が返るか読めば分かる。 メソッド名と実行例はクリックでコピーできる。

注記
  • シグネチャと説明は 公式 Javadoc(Java SE 21)を確認して作成している。Gatherers のみ Java SE 25 の Javadoc を参照した。
  • Stream.gather と Gatherers は Java 24 で正式化された(Java 22・23 ではプレビュー機能)。
  • 実行例の User / Order はレコードを想定した架空の型。User::name のようなアクセサ名は読み替えること。
  • 中間操作は遅延評価で、終端操作を呼ぶまで実行されない。ストリームは終端操作1回で使い切りになる。
