日常的に触れるプロトコルのパラメータを、用途別に1ページへまとめた早見表。 項目名と例はクリックでコピーできる。 数字のコードは「1桁目が結果、2桁目が種類」という共通の読み方があり、HTTP・SMTP・FTP で同じ発想が使える。

該当なし

注記
  • ヘッダ名とステータスコードは IANA のレジストリと各 RFC に基づく。値の一部は実装で拡張されている。
  • ポート番号は既定値で、設定で変えられる。実際の待ち受けは ss -tulnp で確認すること。
  • 例のホスト名・IP・トークンは代表例（example.com / 203.0.113.0/24 / 2001:db8::/32 は文書用に予約された値）。
  • 平文は暗号化されずに流れるもの、破壊的は取り消せない操作、要注意は公開すると事故になりやすいものを指す。
  • HTTP のキャッシュ指示語は組み合わせで意味が決まる。no-cache は「保存するな」ではなく「使う前に検証せよ」。
