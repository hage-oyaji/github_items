Spring アノテーション一覧 Spring Framework 7.0 / Boot 4.1 / 2026-09-04
▸

Spring で使うアノテーションを、DI・Web・データ・Boot・セキュリティ・テストの順にまとめた一覧。 JPA(jakarta.persistence)と Bean Validation(jakarta.validation)も、Spring と組で使うため同じ表に載せている。 アノテーション名と記述例はクリックでコピーできる。 説明は公式ドキュメントの記述を日本語にしたもので、各区分の見出しに所属パッケージを書いてある。

該当なし

注記
  • 説明は公式ドキュメントの記述を日本語化したもの。参照元は Spring Framework 7.0 Javadoc、Spring Boot 4.1 Javadoc / リファレンス、Spring Data JPA / Commons Javadoc、Spring Security リファレンス、Jakarta Persistence 3.1、Jakarta Bean Validation 3.0。
  • バージョン表記のないものは、Spring Framework 5.x / Spring Boot 2.x の頃から使える。「Spring 6.2+」「Spring Boot 3.4+」などの表記があるものは、そのバージョン以降でのみ利用できる。
  • 各区分の見出しに所属パッケージを書いてある。同名で出自の違うもの(@Id @Version @Transient @Cacheable など)は、どちらを import するかで挙動が変わるので注意すること。
  • 「主な属性」は使用頻度の高いものだけを挙げている。全属性は Javadoc を参照すること。
  • 記述例の User / Order などは架空の型。ローカルに Spring 環境が無いためコンパイル・実行による検証はしておらず、公式ドキュメント準拠である。
