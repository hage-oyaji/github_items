VS Code ショートカット索引 v1.127 既定キーバインド

Visual Studio Code の既定キーバインドを用途別に並べた一覧(v1.127 時点)。 キーはクリックでコピーできる。 記号は Cmd = ⌘、Opt = ⌥。 Ctrl+K Ctrl+S のように空白で区切られたものは、順に押す2段階のキー操作を表す。

該当なし

注記
  • このページは 公式の既定キーバインドに基づく。ローカル環境からの抽出ではないため、自分の割当は Ctrl+K Ctrl+S で確認すること。
  • 拡張機能がキーを上書きすることがある。競合はキーボードショートカット画面で確認できる。
  • — は既定のキーが割り当てられていない操作。コマンドパレットまたはUIから実行する。
  • 日本語IMEを使う環境では Ctrl+Space(サジェスト)がIME切替と衝突しやすい。どちらかを再割当するとよい。
  • キー操作の完全な一覧は Ctrl+K Ctrl+R / Cmd+K Cmd+R で公式チートシートが開く。
