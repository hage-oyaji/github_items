Web アプリでよく起きる脆弱性を、「何が起きるか」「なぜ起きるか」「どう防ぐか」の順で並べた早見表。 対策は悪い例と良い例をコードで対比している。項目名と例はクリックでコピーできる。 攻撃名を覚えるより、冒頭の考え方を掴むほうが応用が利く。

該当なし

注記
  • 分類と用語は OWASP Top 10 と CWE の考え方に沿っているが、実務で当たる順に並べ替えている。
  • コード例は要点を示すための断片で、そのまま貼って動くものではない。使っているフレームワークの標準機能を優先すること（大半は既に対策を持っている）。
  • 重大はサーバーやデータを丸ごと失いうるもの、誤解は対策したつもりで守れていない典型を指す。
  • ここに書いたのは自分が開発・運用するシステムを守るための内容。他者のシステムへの試行は、許可を得た診断や自分の検証環境に限ること。
  • 網羅を目的にしていない。実際の設計では OWASP ASVS のような体系的なチェックリストと併用すること。
