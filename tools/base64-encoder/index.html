テキストの変換について

  • 文字列は UTF-8 のバイト列に直してから Base64 にする。btoa() に日本語をそのまま渡すと例外になるが、このツールでは TextEncoder を挟んでいるので問題ない。
  • URL セーフ(RFC 4648 §5)は + を -、/ を _ に置き換え、末尾の = を落とす。JWT やクエリ文字列に載せる形式。
  • デコードはどちらの文字種も受け付ける。-_ は自動で +/ に戻し、足りない = は補う。空白と改行は無視する。
  • テキストのデコードで失敗するのは、Base64 の文字種以外が混じっている場合、長さが 4 で割った余り 1 になる場合、復元したバイト列が UTF-8 として不正な場合。画像を入れたときは「画像」に切り替える。

画像の変換について

  • エンコードはドロップまたはクリックで画像を選ぶ。data URI を選ぶと data:image/png;base64,… の形で出力するので、CSS や HTML にそのまま貼れる。
  • デコードは Base64 でも data: 付きでも受け付ける。形式は先頭のバイト列(マジックナンバー)から判定し、プレビューと保存ボタンを出す。
  • Base64 にすると元のバイト数の約 4/3 に増える。data URI で HTML に埋めると、その分だけ HTML が重くなる。
  • 変換はすべてブラウザ内で完結し、画像もテキストもどこにも送信されない。
