Bedrock の接続設定

入力した値は このタブの sessionStorage にだけ置き、タブを閉じると消える。サーバーにも保存されない。 GitHub Pages は同一オリジンを同じアカウントの全リポジトリで共有するため、長期のアクセスキーではなく STS の一時認証情報（セッショントークン付き）を使うこと。

使い方

  • 左に話し言葉のまま書くか、音声入力で吹き込む。形式を選んで「実行」を押すと、右に整えた文章が出る。
  • 音声入力はブラウザの機能（Web Speech API）を使う。Chrome / Edge / Safari で動作し、Firefox は未対応のためボタン自体を出さない。認識中はマイクの点が明滅する。
  • Chrome の音声認識は音声を Google のサーバーへ送って文字にする。端末内では処理されない。機微な内容はキーボードで入力する。

接続について

  • ブラウザから Bedrock の InvokeModel を SigV4 で署名して直接呼ぶ。署名は Web Crypto で組み立てており、外部ライブラリは読み込まない。
  • AWS のサービスエンドポイントは CORS ヘッダーを返さない。ブラウザから直に叩くと、署名が正しくてもブラウザ側で遮断されることがある。その場合は「接続設定」の ENDPOINT に、同じ形式を中継する自前のプロキシ（API Gateway + Lambda など）の URL を入れる。失敗時はどちらが原因かを画面に出す。
  • 使うモデルは設定で変えられる。推論プロファイル経由なら apac.anthropic.… のような ID を入れる。
  • 入力文はモデルへの問い合わせにのみ使う。このページ自体はどこにも記録を残さない。
