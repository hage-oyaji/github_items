2つの方式の違い

  • Component(encodeURIComponent)は / ? & = # + も含めて変換する。クエリの値ひとつ分を包むときはこちら。
  • URI 全体(encodeURI)は URL の区切り文字を残す。URL 全体をまとめて安全化したいときに使う。区切り文字が壊れないかわり、値に & が含まれていても変換されない。
  • どちらも A-Z a-z 0-9 - _ . ! ~ * ' ( ) は変換しない。半角スペースは %20 になる。フォーム送信で使う + 形式ではない。
  • デコードが失敗するのは、% の後ろが16進2桁でない場合と、UTF-8 として不正なバイト列になる場合。
